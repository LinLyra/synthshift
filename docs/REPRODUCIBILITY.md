# Reproducibility policy

- Every reported run has a config file, seed, code commit, and registry entry.
- Raw data and large checkpoints are stored outside Git.
- Compact result tables include provenance and dataset split hashes.
- Exploratory and confirmatory analyses are labelled separately.
- Final figures are generated from retained result tables, not edited manually.
- Upstream repositories and model weights are pinned by commit or content hash.
